# Prototype Ideator

AI agents read documents about a company, map its business issues and KPIs, and propose agentic-AI prototypes that each improve a named KPI. Code scores and ranks the ideas; a person shortlists the one to build and downloads a report.

**Status:** planning, 23 November 2026. Nothing runs yet; the plan is in [PLAN.md](PLAN.md).

Live site, once published: <https://victorpflueger.github.io/PrototypeIdeator/>

## What will be real and what simulated

The simulation will play three fictional companies with illustrative figures: recorded agent answers, real scoring rules, no API key and no cost. A live run will use your own documents and your own Claude API key; the key and everything you enter stay in the browser tab's memory and go only to Anthropic's API. Enter public information only: never confidential, personal or otherwise protected data.
